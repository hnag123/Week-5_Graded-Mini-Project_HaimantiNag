# dotenv  loads key-value pairs from .env file into my application's environment variables so I can manage configuration and secrets outside my source code.
# Together, these seven libraries (listed below) form the standard toolkit for building scalable AI data-processing pipelines in Python. 
# openai (AI Integration). Connects my script to OpenAI's API to send prompts and receive generated text, structured data, or embeddings. 
# asyncio (Concurrency & Speed). Enables asynchronous programming using async and await so my script can send multiple API requests at the same time instead of waiting for them one by one.
# pandas (Data Manipulation). Loads, cleans, and structures tabular data into DataFrames. 
# json (Data Parsing). Converts data between Python dictionaries and JSON strings. 
# os (Environment & File System). Interacts with operating system to safely read secret environment variables (like OPENAI_API_KEY) without hardcoding them into your script.
# re (Text Cleaning & Extraction). Provides regular expressions to search, match, or clean text patterns.
# time (Rate Limiting & Benchmarking). Tracks how long scripts take to execute and pauses execution (time.sleep()) when needed.
